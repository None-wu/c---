# 学习管理系统

基于 GTK 开发的学习管理系统，帮助学生管理课程、任务、心情记录和错题集。

## 功能特点

### 🎓 学生信息管理
- 个人信息录入（姓名、专业、年级）
- 学习基础评估
- 学习目标设定（考研、就业、出国、考公等）

### 📅 课程表管理
- 课程信息管理（课程名称、时间、教室）
- 按星期显示课程安排
- 支持 CSV 格式导入/导出

### ✅ 学习任务管理
- 创建学习任务
- 设置截止日期和预计时长
- 任务完成打卡

### 😊 心情记录
- 记录每日学习状态（高效、突击、放松、迷茫、疲惫）
- 根据心情提供学习建议

### 📊 学习统计
- 任务完成情况统计图表
- 饼图展示学习时间分布

### 📚 错题集
- 导入错题图片
- 按科目和难度分类管理

## 技术栈

- **框架**: GTK 3
- **语言**: C
- **安装包**: NSIS
- **平台**: Windows

## 安装说明

### 方法一：使用安装包

1. 运行 `Study_Management_Setup.exe`
2. 按照安装向导完成安装
3. 安装完成后在开始菜单或桌面找到快捷方式

### 方法二：源码编译

```bash
# 确保已安装 GTK 开发环境
gcc -o study_system.exe 学习管理系统.c `pkg-config --cflags --libs gtk+-3.0`
```

## 使用说明

1. **启动程序**: 双击桌面快捷方式或从开始菜单启动
2. **填写个人信息**: 在"学生信息"页面填写姓名、专业等信息
3. **添加课程**: 在"课程表"页面添加或导入课程
4. **创建任务**: 在"学习任务"页面创建学习任务
5. **记录心情**: 在"心情记录"页面选择今日状态
6. **查看统计**: 在"学习统计"页面查看学习数据
7. **管理错题**: 在"错题集"页面导入错题图片

所有数据自动保存到 `study_data.txt` 文件，位于程序安装目录。

## 系统要求

- Windows 7 及以上版本
- 需要管理员权限进行安装
